# Cinder Manga & Manhwa Extras

Public Cinder Reader repository for additional English manga and manhwa sources.

## Installation
Add this URL in Cinder → Settings → Extensions → Add Repository:

`https://raw.githubusercontent.com/Anionyx/cinder-manga-manhwa-extras/main/repo.json`

## Current status

- MangaKatana — experimental adapter published, **not yet tested** against live search, chapter, or image retrieval.
- The following sources are **planned, not installed and not yet functional**:

- MangaFire
- MangaPlus
- Mangapill
- AllManga
- Flame Comics
- HiveToons
- MangaDemon
- MangaNato
- MangaBat
- Toonily
- ManhwaTop

Extensions must implement Cinder's JavaScript API (search, details, chapters, pages) and pass live tests before inclusion in `repo.json`. A source appearing in Paperback/Inkdex does not make its extension compatible with Cinder.

No secrets or tokens should be committed.
